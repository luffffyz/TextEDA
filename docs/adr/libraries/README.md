# Libraries — decisions

## Scope

Libraries as material: the formats this project writes, what a library claim is worth, and how trust in a library you do not own is recorded.

## Not here

- The project tree's ownership model — [ADR-0107](../project/0107-project-tree-has-owners.md).
- What a device may state — [ADR-0124](../devices/0124-device-vocabulary-and-parameter-roles.md).

## Reading order

1. [0129](0129-footprint-format-and-geometry.md) — the footprint format is ours; the KiCad format is an export artifact.
2. [0130](0130-symbol-format.md) — the symbol format is ours, and a pin's facts live in the device.
3. [0131](0131-the-reference-project-is-self-built.md) — the reference project is entirely self-built.
4. [0132](0132-libraries-are-unverified-facts.md) — a library is an unverified fact that carries its provenance.
5. [0133](0133-trust-in-a-library-you-do-not-own.md) — trust in a library you do not own.
