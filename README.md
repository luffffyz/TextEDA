# TextEDA

[English](README.md) | [简体中文](README_cn.md)

Describe a piece of hardware as **human-written text**: the schematic (`sch`) and the PCB (`pcb`) are two independent, sibling descriptions; the IR is the single source of truth, and both the source syntax and any rendered output are derivatives.

Built for agents: machine-parsable, verifiable, locatable errors. Humans only review.

> Licensed under **Apache-2.0** (see `LICENSE` / `NOTICE`). The project is a work in progress.
>
> **The contract layer is open source forever**: `teda.md` / `spec/` / `schemas/` / `examples/` / `tests/` stay public and implementable, never closed for commercial reasons. The implementation layer (`packages/`) may be relicensed separately. The positioning is a **standard proposal** — let others build tools around it.
>
> The GitHub repo is **currently private**. The license and the "will be public" commitment are settled, and the pre-publication sweep is done (`bun run check:public` passes: no vendor PDFs in the history, no credentials, no maintainer paths). Flipping the switch is a pending manual step. See [ADR-0015](docs/adr/0015-licensing-and-open-standard.md) and `docs/backlog.md` F6.

## What works now

```bash
bun install
bun test                # unit + contract + round-trip
bun run typecheck       # all six packages through tsc
bun run lib:verify      # library closure, **zero external dependencies**
bun run lib:verify:kicad  # optional: adds the KiCad interoperability section
bun run check:links      # every Markdown link and ADR cross-reference resolves
bun run check:public     # pre-publication sweep: no vendor PDFs in the history, no credentials
bun run preview symbol bq24610rger     # draw a symbol (no KiCad needed)
bun run preview component bq24610rger  # draw a component's symbol + footprint
bun run fmt:teda --check examples/reference-project   # canonical-form check
bun run compile:schematic examples/reference-project mcu-board   # board IR (diagnostics carry error codes)
bun run check examples/reference-project          # validate every board (ERC + IR contract)
bun run texteda netlist examples/reference-project --board mcu-board  # netlist = connectivity projection of the IR
bun run texteda init ./my-board        # generate an empty project skeleton
```

Current state: the front half of the toolchain is landed — language → IR → KiCad export → preview rendering. `schematic` / `page` parsing (instances, nets, ports, constraints, buses, page flattening), `pcb` parsing (12 sections → `pcb` IR), the canonical formatter for all four description types, connectivity ERC and sch↔pcb binding checks (`packages/core`) all work. Board-level design (placement, routing, manufacturing output) is not implemented; KiCad stays the manufacturing exit ([ADR-0005](docs/adr/0005-manufacturing-output.md)).

Two agent-facing artifacts (both generated by `bun run gen`, never hand-edited):

| File | Answers |
|---|---|
| `docs/error-codes.md` | diagnostic code → meaning, severity, spec section |
| `docs/ir-reference.md` | IR field → type, required, **unit**, description (coverage list at the end) |

## Layout

| Path | What it is |
|---|---|
| `AGENTS.md` | **Primary doc**: what the project is, the non-negotiable invariants, acceptance criteria |
| `LICENSE` / `NOTICE` | Apache-2.0 and attribution |
| `teda.md` | `.teda` syntax overview |
| `spec/` | Per-description specs: `project` / `schematic` / `pcb` / `symbol` / `footprint` / `system` |
| `schemas/ir/v0.1/` | IR contract (JSON Schema 2020-12, the only contract) |
| `packages/ir` | IR types and contract validation |
| `packages/parser` | `.teda` → IR, including `fmt` (canonical form) |
| `packages/core` | Pure rules: connectivity ERC and sch↔pcb binding, no fs access |
| `packages/exporter` | footprint / symbol → KiCad (`.kicad_mod` / `.kicad_sym`); netlist |
| `packages/renderer` | Reference renderer: IR → drawing commands → SVG ([ADR-0014](docs/adr/0014-reference-renderer.md)) |
| `packages/cli` | `texteda init` / `compile` / `check` / `netlist` ([ADR-0019](docs/adr/0019-agent-contract-reference-and-check-entry.md)) |
| `examples/reference-project/` | Self-contained reference project: 22 components / 15 symbols / 16 footprints, all libraries self-built |
| `docs/adr/` | Architecture decision records, 0001–0019 ([full index](docs/adr/README.md); 0017 and 0020 reserved) |
| `docs/backlog.md` | Open work items |

## Language policy

Source code (`.ts`, schemas, and `.teda` examples) is English-only. Design docs under `docs/` and `spec/` are written in Chinese, with one exception: `docs/adr/` is English, because ADRs are part of the contract layer — `spec/`, `schemas/` and `teda.md` cite their decisions by number, and third-party implementers need to read them. `README.md` is the English entry point and `README_cn.md` carries the Chinese.
